# Siraj Builders — Premium Static Website

A redesigned static HTML/CSS/JavaScript construction website using the Siraj Builders brand palette.

## Run locally

Use any static server from this directory, for example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080/`.

## Important

- Contact form uses a local/demo success state; it does not claim to send email.
- Company-specific claims such as phone, location, years, certifications, awards and project statistics are intentionally not fabricated.
- Replace temporary project/testimonial content with verified company information before launch.
- Images are loaded from Unsplash CDN URLs and can be replaced with approved Siraj Builders assets.
